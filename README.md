# DriveHub – Sistema de Alquiler de Autos

Integrantes:

- Nahuel Raimondi
- Ludmila Tévez
- Jorge Rivas
- Emmanuel Escobar

Este proyecto es un sistema para gestionar una plataforma de alquiler de autos.  
Permite registrar vehículos, crear reservas, verificar disponibilidad, calcular costos según temporada y manejar el estado de cada auto (disponible, alquilado o en mantenimiento).
Incluye distintos tipos de vehículos (Sedan, SUV, Compacto), temporadas (alta, media, baja) y toda la lógica necesaria para administrar alquileres, rentabilidad y mantenimiento, con sus respectivos tests, diagramas de clases y diagrama de secuencia.
