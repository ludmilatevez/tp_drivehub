    Interface default

    Interfaz que define el contrato para los distintos estados de un vehículo dentro del patrón de diseño State. Cada implementación representa un estado concreto (por ejemplo: Disponible, EnAlquiler, EnMantenimiento), y controla cómo debe comportarse el vehículo cuando se solicita una acción según su estado actual. Este patrón permite que 'Vehiculo' delegue el comportamiento específico en el objeto de estado correspondiente.

    interface default {
        alquilar(): void;
        devolver(): void;
        estaDisponible(): boolean;
        estaEnAlquiler(): boolean;
        estaEnMantenimiento(): boolean;
        finalizarMantenimiento(): void;
        getNombre(): string;
        iniciarMantenimiento(): void;
        setContexto(vehiculo: default): void;
