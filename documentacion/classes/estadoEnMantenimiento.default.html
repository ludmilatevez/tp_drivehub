    Class default

    Representa el estado "En mantenimiento" dentro del patrón State utilizado por 'Vehiculo'. Un vehículo en mantenimiento:

    • No puede alquilarse.
    • No puede devolverse, porque ya está fuera de servicio.
    • No puede iniciar nuevamente el mantenimiento.
    • Puede finalizar el mantenimiento, lo que cambia su estado a 'EstadoDisponible'. Este estado modela el comportamiento del vehículo cuando se encuentra temporalmente fuera de uso.
