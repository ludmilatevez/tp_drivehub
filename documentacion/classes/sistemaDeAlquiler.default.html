    Class default

    Representa el sistema principal encargado de gestionar:

    • Vehículos disponibles para alquiler.
    • Reservas creadas por los clientes.
    • Validación de disponibilidad.
    • Procesos de devolución y cálculo de costos. Este sistema coordina los repositorios, actualiza estados de los vehículos y calcula la rentabilidad generada por cada alquiler.

    entregarVehiculo

    • entregarVehiculo(reserva: default, kilometrajeTotal: number): void

      Procesa la devolución de un vehículo asociado a una reserva. Flujo completo:

      1. Obtiene vehículo y datos de la reserva.
      2. Cambia el estado del vehículo a disponible.
      3. Actualiza:
      • Kilometraje
      • Contador de alquileres
      1. Verifica si el vehículo necesita mantenimiento:
      • Por kilometraje
      • Por tiempo
      • Por cantidad de alquileres Si lo requiere:
      • Cambia estado a mantenimiento.
      • Aplica costo de mantenimiento reduciendo rentabilidad.
      1. Calcula costo final del alquiler:
      • Días reservados
      • Temporada
      • Kilometraje
      1. Aumenta la rentabilidad en base al costo final.
      2. Elimina la reserva del repositorio.

      Parameters

      • reserva: default

        Reserva que se está cerrando.

      • kilometrajeTotal: number

        Kilómetros recorridos durante el periodo de alquiler.

      Returns void
